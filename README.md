# CITED_
Serious game to teach researchers about the meaning of the Journal Impact Factor and similar metrics. Human idea, Claude Sonnet 5 code, OpenAlex data. 

## Cite as
Röseler, L. (2026). CITED_ [Web-based game]. https://lukasroeseler.github.io/cited/

## Analysis report
An accompanying analysis of works by FORRT contributors, asking how closely a
journal's mean citedness tracks the citation counts of individual papers:
[forrt-members/report.html](https://lukasroeseler.github.io/cited/forrt-members/report.html).
Retrieval and analysis code, and the retrieved data, are in
[`forrt-members/`](forrt-members/).
